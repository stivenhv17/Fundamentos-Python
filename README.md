## Operadores matemáticos

En el archivo `OperadoresMatematicos.py` se utilizan los siguientes operadores:

- Suma (`+`)
- Resta (`-`)
- Multiplicación (`*`)
- División (`/`)
- División entera (`//`)
- Módulo (`%`)
- Potencia (`**`)

### Lógica utilizada

El programa solicita dos números al usuario mediante `input()`. Después realiza las operaciones matemáticas utilizando los operadores de Python y muestra los resultados con `print()`.

### Ejemplo de salida

```
Ingrese el primer número: 10
Ingrese el segundo número: 5

Suma: 15
Resta: 5
Multiplicación: 50
División: 2.0
División entera: 2
Residuo: 0
Potencia: 100000
```

## Cómo ejecutar los programas

1. Abrir una terminal.
2. Ubicarse en la carpeta del proyecto.
3. Ejecutar el archivo deseado:

```bash
python src/Sesion3/OperadoresMatematicos.py
```
